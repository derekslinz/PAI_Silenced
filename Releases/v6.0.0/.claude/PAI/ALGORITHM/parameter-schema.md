Require selectionPressure ≥ . if ideaVolume > and maxCycles > . - `generativeTemperature` ↓ + `domainDiversity` ↓ + `mutationRate` ↓ — everything conventional and static. Suggest maxCycles: . - `contextCarryover` ↑ + `maxCycles` ↑ + `ideaVolume` ↑ — context window overflow risk. --- Meta-Learner Interaction Model The Meta-Learner (Ideate Phase ) adjusts parameters within bounds: . User-set parameters define INITIAL STATE and BOUNDS . Meta-Learner adjusts WITHIN bounds during execution . Locked parameters cannot be adjusted . All adjustments logged with rationale Default locked params: `parallelAgents`, `maxCycles`, `maxIterations`, `targetMetric` Auto-locked: Any parameter the user explicitly set via `--param` override Safeguards: - Max adjustment per cycle: % of parameter range - Max cumulative drift from initial value: % of range - Rationale required for every adjustment Config structure: ```yaml meta_learner: locked_params: [parallelAgents, maxCycles] max_adjustment_per_cycle: . max_cumulative_drift: . ``` --- ISA Frontmatter Serialization ```yaml algorithm_config: preset: explore Layer (optional) focus: .
