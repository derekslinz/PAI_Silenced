# AI Writing Patterns — Avoid List

> Bootstrap default. The assistant references this when writing in your voice
> to scrub AI-isms.

Generated text has tells. This file is the running list of patterns to
detect and remove. The `_WRITING` skill (rewrite + detect modes) reads
this list as its rule source.

## P0 — Credibility killers (always remove)

- "Let me know if..." closers
- "I hope this helps" / "Hope this helps"
- "I'd be happy to..."
- "Feel free to..."
- "It's important to note that..."
- "In conclusion..." / "To summarize..."
- "...load bearing..."
- "...Why this matters..."
- "...and that matters..."

## P1 — Obvious AI smell (almost always remove)

- "Here's the thing..."
- "Here's how it works..."
- "Not just X — Y"
- "Not X. Y."
- "The cool part?"
- "Let's dive in"
- "--" : Limit usage to once per paragraph at MOST.
